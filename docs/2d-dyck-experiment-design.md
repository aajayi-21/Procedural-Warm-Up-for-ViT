# Experiment Design: 2D Dyck Procedural Warm-Up for Vision Transformers

**Status:** pre-registration-style design document. Continues the H1–H5 post-mortem
(`report.md`) into a concrete experimental program, H6–H11. All baselines and thresholds
are tied to numbers already in `results/reports/` or in the parent paper
(Shinnick et al., arXiv:2511.13945v2) and the 2D Dyck paper
(Crespi Reghizzi et al., arXiv:2307.16522v2).

---

## 1. What this program must explain or exploit

The CA post-mortem established three facts that constrain any next experiment:

1. **The transferable triad.** k-Dyck's gain (in-repo CIFAR-100: 72.64–72.80 vs. random
   70.02) is attributed to three properties its objective *forces*: (a) long-range
   binding (stack tracking under close-only masking), (b) a rich type space
   (K = 130 tokens), (c) a constraint *distribution* rather than a deterministic map.
   CA had none by default; retrofitting (b) via block tokenization and partially (a) via
   forward masking recovered most but not all of the gap (best CA: 72.22).
2. **Operator controls are decisive.** `iid-true` (66.81) vs. `iid-shuffled` (66.90)
   showed the CA rule itself transfers ~nothing. Every new source must ship with its own
   shuffled-operator control from day one, not as an afterthought.
3. **The determinacy requirement (report §5).** Re-mapping dimensionality fails when it
   decouples position from role. Per-sample layout randomization (spatial-dyck permuted,
   66.93) is under-determination and is fatal; a fixed bijection (CA's row-major flatten)
   merely *obscures* structure. And masked targets must be **determined by the visible
   context**, else the model fits marginals — the regime that produced the worst score in
   the study (`iid-static`, 65.72).

2D Dyck languages are attractive precisely because they are the first candidate that
keeps the full triad *and* is natively 2D (not a re-layout): corner-quadruple matching
gives long-range binding in two axes; the alphabet Δ_k = {aᵢ, bᵢ, cᵢ, dᵢ} gives 4k
content symbols; generation is stochastic under hard global constraints. The published
hierarchy **DW_k ⊊ DN_k ⊊ DQ_k ⊊ DC_k** additionally provides a built-in determinacy
gradient, mirroring the parent paper's Chomsky-hierarchy sweep.

One warning flag carries over: the only 2D presentation tested so far — spatial-dyck —
*hurt* (70.42 nested / 66.93 permuted vs. 72.64 for 1D). The design below treats
"native 2D structure helps" as a hypothesis to be tested (H7), not an assumption.

## 2. Design principles (binding for every experiment below)

| # | Principle | Operationalization |
|---|---|---|
| P1 | **Reproduce a paper number first** | Phase 0 gate: re-run `cifar100-dyck` and `cifar100-random` on the current branch; must land within ±0.4 of 72.64 and 70.02 before any new generator code is trusted. |
| P2 | **Infrastructure parity** | Branch from `procedural-warmup-vit`; 2D generators live in `generators/grammars_2d/` beside existing ones. Same trainer (`warmup/trainer.py`), same frozen orthogonal token embeddings, same MLM head, same 15k steps × 256 batch, same downstream recipe (300 epochs, ViT-T/16 for CIFAR-scale). Only the data source and (where the hypothesis demands it) the position code / masking mode vary. |
| P3 | **Token-budget parity** | Every warm-up sees the same number of supervised tokens. 1D k-Dyck uses 196-token sequences; 2D pictures are fixed at **14×14 = 196 cells**, mapping one cell → one token → one ViT position. No condition gets more compute. |
| P4 | **Operator control ships with the source** | Every 2D Dyck condition is paired with a matched-marginals control (H9) generated by the same code path with the constraint structure destroyed. |
| P5 | **Determinacy-audited masking** | The masking scheme must guarantee (or measure) that each masked target is uniquely determined by visible context. A determinacy auditor is part of the generator deliverable, not optional tooling. |
| P6 | **Fixed layout, no per-sample re-mapping** | Pictures are laid on the token grid by the identity map (cell (r,c) → token r·14+c) in every condition. Per-sample D4/permutation is banned (spatial-dyck lesson). Position-shortcut risk is handled by an explicit ablation (H7c), not by randomization. |
| P7 | **Seeds before claims** | The in-repo Dyck seed spread is 0.67 pts (72.13–72.80). Single-run deltas below ~0.7 are noise. Screening runs: 1 seed. Any comparison that feeds a verdict: 3 seeds, report mean ± std; a difference counts only if |Δmean| > max(0.7, 2·pooled std). |

## 3. Shared experimental infrastructure

**Models.** ViT-T/16 for all CIFAR-scale work (CIFAR-10/100, STL-10, Tiny-ImageNet,
FOOD-101); ViT-B/16 reserved for the single Phase-3 ImageNet-1K confirmation. Standard
Dosovitskiy architecture, 16×16 patches, patch-bypass interface for symbolic warm-up
(tokens enter as embedding indices, bypassing the conv patch stem, as in the repo).

**Warm-up recipe (parent paper Table 9, unchanged).** Masked-token prediction; batch 256;
15,000 steps; mask ratio 0.5 (structure-targeted variant per condition, §H11); AdamW,
lr 2e-3, wd 0.05, cosine decay, 1k warmup steps.

**Downstream recipe.** Parent-paper Section 4.1 setup: 300 epochs, 50 warmup epochs,
batch 512, RandAugment/Mixup/CutMix/label smoothing. Primary metric: CIFAR-100 best
top-1. Secondary (Phase 2+): Tiny-ImageNet, STL-10, FOOD-101, CIFAR-10.

**Anchor numbers (all from `results/reports/` unless noted).**

| Anchor | CIFAR-100 top-1 |
|---|---:|
| k-Dyck (best of 3 in-repo runs) | 72.80 |
| k-Dyck (canonical run) | 72.64 |
| k-Dyck seed floor | 72.13 |
| Best CA after engineering (block, s1) | 72.22 |
| k-Dyck + 2D pos-embed | 72.19 |
| Random init | 70.02 |
| Spatial-Dyck nested / permuted | 70.42 / 66.93 |
| Parent paper ViT-T C100: warm-up / random (3 seeds) | 71.98 ± 0.74 / 68.52 ± 0.27 |
| Parent paper ImageNet-1K ViT-B delta | +1.72 |

Note the in-repo random baseline (70.02) is ~1.5 pts above the paper's (68.52); all
verdicts use **in-repo** anchors, on the principle that both arms of any comparison run
through identical local infrastructure.

**Vocabulary bookkeeping.** Δ_k has 4k content symbols; with 2 specials,
K = 4k + 2. k = 32 gives K = 130 — *exactly* the k-Dyck vocabulary that succeeded and
the ~130-way space that block tokenization had to import for CA. k = 32 is therefore the
default; H10 sweeps it.

**Position encodings.** `sincos2d` is the default for 2D conditions (it is the code that
exposes grid adjacency; leaving it random would repeat CA's H3 failure). `random` frozen
positions are retained as an ablation arm (H7).

## 4. Hypotheses and experiments (H6–H11)

Numbering continues from the CA post-mortem's H1–H5. H6 is the headline; H7–H11 isolate
mechanisms and guard against the failure modes already observed.

### H6 — Well-nested 2D Dyck warm-up transfers at least as well as 1D k-Dyck

**Claim.** DW_k warm-up, presented natively on the 14×14 token grid with `sincos2d`
positions and determinacy-audited masking, reaches the k-Dyck band on CIFAR-100.

**Why DW_k first.** It is the most constrained family (safest determinacy properties),
has a recursive generative definition (Def. 2 of the 2D Dyck paper: accretion of a
well-nested picture with corner quadruples, plus concatenations/Simplot closure) that
supports direct stochastic sampling with a flush guarantee — the exact analog of the 1D
generator's stochastic open/close with stack flush (`data/dyck/generator.py`).

**Conditions.**

| Arm | Source | Pos code | Masking |
|---|---|---|---|
| A (treatment) | DW_32, native 2D | sincos2d | corner-close-only (§H11) |
| B (baseline) | 1D k-Dyck, K=130 | random (canonical) | close-only |
| C (baseline) | random init | — | — |
| D (control) | DW_32 marginal-shuffle (H9a) | sincos2d | same as A |

**Metrics & decision thresholds (3 seeds each, mean ± std).**
- **Success:** A ≥ 72.0 and A − D ≥ 1.0 → the 2D constraint structure itself transfers;
  proceed to the H8 gradient with full priority.
- **Partial:** 70.7 ≤ A < 72.0 (beats random by >0.7 but below the Dyck band) → 2D Dyck
  transfers something but native-2D presentation costs; H7 becomes the priority.
- **Failure:** A ≤ 70.7 or A ≈ D → either presentation kills it (check H7) or the corner
  constraint is locally shortcut-able (check the determinacy audit and H11 masking arms).
  A ≈ D with decent absolute numbers would be the CA story repeating: generic properties
  transferring, operator not.

**Predicted outcomes under competing explanations.**
- If the *triad theory* is right (structure + vocabulary + constraint distribution are
  sufficient and presentation is recoverable when position codes expose geometry):
  A ≈ B ± 0.5, A ≫ D.
- If the *1D-temporal-order theory* implied by spatial-dyck is right (transformer warm-up
  benefits require sequential order regardless of the source's native geometry):
  A lands near spatial-dyck-nested (~70.4) even with sincos2d, and H7's rasterized arm
  beats the native arm.
- If *vocabulary alone* drives most of the effect (strong H2 world): A ≈ D ≈ block-CA
  (~71.4–72.2), i.e. the control does almost as well as the treatment.

### H7 — Presentation: native 2D beats rasterized 1D iff the position code exposes geometry

**Claim.** The spatial-dyck failure was a presentation artifact (per-sample
randomization → under-determination), not evidence against 2D. For a natively 2D
language with a fixed layout, native presentation + sincos2d ≥ row-major rasterization,
and sincos2d is necessary for that advantage.

**Conditions (all DW_32, corner-close-only masking, 1 seed screen → 3 seeds for the
winning contrast).**

| Arm | Layout | Pos code |
|---|---|---|
| A | native 2D grid | sincos2d |
| B | native 2D grid | random frozen |
| C | row-major rasterized to 1D | random frozen |
| D | row-major rasterized to 1D | sincos1d |
| E (H7c shortcut probe) | native 2D grid, ±2-cell translation jitter with padding | sincos2d |

**Readouts.** Downstream C100 plus two cheap diagnostics on the warm-up model itself:
(i) masked-corner accuracy vs. distance to matching corners (does the model bind at
range?); (ii) attention-distance profiles per block (the CA failure signature was
short-range attention).

**Decision logic.** A > C by >0.7 confirms native-2D value; B ≈ C localizes the CA-era
H3 mechanism (geometry obscured by position code) in a clean setting — and
retro-actively fills the untested **CA + sincos2d cell** flagged in the post-mortem:
run one `rule110 + sincos2d` arm here (1 seed) to close that loop cheaply.
E ≈ A rules out absolute-position shortcuts from the fixed layout (P6); E ≪ A means
the model was leaning on absolute position and jitter should become default.

### H8 — The DW ⊊ DN ⊊ DQ ⊊ DC inclusion chain is a usable determinacy/constraint gradient

**Claim.** Transfer quality varies monotonically along the hierarchy, peaking where
constraint richness is maximal *subject to* masked targets remaining determined —
the 2D analog of the parent paper's finding that Type-2/Type-1 grammars beat both
regular and unrestricted extremes.

**Conditions.** DW_32, DN_32, DQ_32, DC_32, each with matched generator statistics
(picture size 14×14, matched symbol marginals where achievable), each with its H9
control, sincos2d, determinacy-audited masking. 1 seed screen across all four; 3 seeds
on the best and worst.

**Key measured covariate.** Per-family *determinacy rate*: fraction of maskable cells
whose value is uniquely forced by the visible context (computed exactly by the auditor
for DW/DN; estimated by constraint propagation + sampling for DQ/DC). Report §5 predicts
DC_k pictures under-determine completions more (row/column projections admit multiple
structures).

**Decision thresholds.**
- A monotone or peaked pattern with spread >0.7 across families → the hierarchy is a
  real experimental axis; write it up as the 2D counterpart of the Chomsky sweep.
- Flat within ±0.7 → family identity doesn't matter beyond the shared triad; deprioritize
  DN/DQ/DC generator investment.
- DC_k below random (<70.0) with low measured determinacy → confirms the §5 prediction
  that under-determined masking reproduces the `iid-static` degenerate regime; this is a
  *useful* negative that validates the determinacy theory causally.

**Predicted outcomes.** Triad theory predicts transfer tracks (constraint richness ×
determinacy rate), likely peaking at DN_k or DQ_k rather than either extreme.

### H9 — Operator controls: the 2D constraint, not its texture, carries the gain

Two controls, both mandatory (P4), analogous to the decisive `iid-true`/`iid-shuffled`
pair:

- **H9a — marginal shuffle.** Sample a valid DW_k picture, then permute cell contents
  uniformly at random across positions. Preserves symbol marginals and picture size;
  destroys all matching structure. This is the paired control in every H6/H8 arm.
- **H9b — projection-preserving scramble (stronger, DC-specific).** Keep every *row* a
  valid 1D Dyck word but randomize across rows so columns are not Dyck. Any DC_k gain
  over H9b isolates the genuinely 2D (row×column joint) constraint from "196 tokens of
  1D Dyck rows." This is the sharpest test that 2D-ness per se contributes.

**Decision threshold.** Treatment − H9a ≥ 1.0 (3 seeds) to claim the operator transfers;
DC − H9b ≥ 0.7 to claim specifically-2D structure transfers. If treatment ≈ H9a but both
beat random, the honest conclusion is the CA conclusion again — generic token statistics
plus vocabulary, not structure — and the program stops before ImageNet.

### H10 — Vocabulary: the 4k corner alphabet reproduces the k-Dyck vocabulary curve

**Claim.** Downstream accuracy vs. k is peaked at intermediate vocabulary, echoing the
parent paper's Table 11 (k=16: 69.05, k=32: 69.78, k=64: **71.98**, k=80: 71.83) and the
CA block-tokenization result (H2: vocabulary is *a* factor, not the whole story).

**Conditions.** DW_k for k ∈ {8, 16, 32, 64} → K ∈ {34, 66, 130, 258}. 1 seed each,
3 seeds at the empirical peak. Frozen orthogonal embeddings cap K at the embedding dim —
verify K=258 fits ViT-T's width (192) or note the K=258 arm requires the scaled-identity
fallback; if it doesn't fit cleanly, cap the sweep at k=47 (K=190) and say so.

**Interpretation.** If the curve's shape matches Table 11 but the *level* stays below
1D Dyck at every k, vocabulary is exonerated and structure/presentation (H6–H8) is where
the gap lives.

### H11 — Masking: structure-targeted, determinacy-audited masking is necessary

**Claim.** The 2D analog of close-only masking is required; uniform random masking on
2D Dyck reproduces the CA failure (H5) even though the source has long-range structure.

**Masking modes (DW_32, native 2D, sincos2d).**

| Mode | Definition | Determinacy |
|---|---|---|
| corner-close-only | mask only d-corners (bottom-right); each is forced in type and position by its rectangle's visible a,b,c corners | exact, by construction |
| audited-random | mask ratio 0.5 uniform, then *unmask* any cell the auditor cannot prove forced | exact, by filtering |
| uniform-random | BERT/MAE default | unaudited |
| row-forward | mask the bottom m rows (2D analog of CA `forward` mode, the lesson-carrying mode) | partial |

**Decision.** corner-close-only ≥ audited-random > uniform-random by >0.7 supports H11
and the §5 determinacy requirement causally. If uniform-random ties corner-close-only,
masking targeting matters less in 2D than the 1D story implied — worth knowing either way.

## 5. Generator implementation plan (`generators/grammars_2d/`)

Module layout mirrors the existing per-source pattern (no premature generalized
interface):

```
generators/grammars_2d/
  dw.py          # well-nested sampler (recursive accretion + concatenation)
  dn.py          # neutralizable sampler (reverse-neutralization expansion)
  dc.py          # crossword sampler (row-column constraint solver)
  dq.py          # quaternate filter/sampler over dc.py (circuits ≤ 4)
  validate.py    # membership checkers, one per family (independent of samplers)
  audit.py       # determinacy auditor for masking (P5)
  controls.py    # H9a marginal shuffle, H9b projection-preserving scramble
  tokenize.py    # Δ_k → ids, K = 4k + 2, fixed cell→token bijection (P6)
```

**DW_k sampler.** Direct stochastic implementation of Definition 2: with probability
p_acc perform corner accretion around the current picture (choosing quadruple index
i ~ Uniform(k)), else horizontal/vertical concatenation of two recursively sampled
sub-pictures; rejection-resize to exactly 14×14 (even dimensions guaranteed by
construction; oversample and reject, or size-conditioned recursion — measure yield
first, optimize only if yield < ~1%). p_acc plays the role of the 1D generator's
p_open = 0.6 and is tuned so depth statistics roughly match the 1D nesting-depth
distribution — this keeps the "difficulty" knob comparable across 1D/2D arms.

**DN_k sampler.** Run neutralization in reverse: start from an all-neutral picture and
iteratively expand neutral 2×2 blocks into corner quadruples, sampling expansion sites
and indices stochastically until no neutral cells remain and size is 14×14.

**DC_k sampler (hardest; budget accordingly).** Row-column joint constraint: every row a
Dyck word over [aᵢ,bᵢ]/[cᵢ,dᵢ], every column a Dyck word over [aᵢ,cᵢ]/[bᵢ,dᵢ].
Plan of attack, in order: (1) constraint propagation + randomized backtracking on the
14×14 grid (feasible at this size; profile first); (2) if yield is poor, composition
from circuit primitives (the paper shows DC pictures decompose into alternating
row/column matching circuits of length 4, 8, …); (3) SAT/CP-SAT encoding as fallback.
**Sampler bias is a real validity threat here** (backtracking order shapes the
distribution); mitigate by logging structure statistics (circuit-length histograms,
match-distance distributions) and reporting them alongside results, and by comparing two
independent sampling strategies on a 1-seed screen before trusting DC results.

**Auditor (`audit.py`).** For a masked cell set M and visible context V, decide per cell
whether the family's constraints force a unique value. Exact for DW/DN (rectangle
partition structure is recoverable from V by parsing); for DC, run constraint
propagation to fixpoint and label cells `forced` / `ambiguous` / `unknown`, masking only
`forced` cells in audited modes and *reporting the measured determinacy rate per family*
(the H8 covariate).

**Validation gates before any GPU time.**
1. Property tests: every sampler output passes its `validate.py` checker (10⁵ samples).
2. Inclusion sanity: sampled DW pictures pass the DN checker; DN pass DQ; DQ pass DC
   (empirical check of DW ⊊ DN ⊊ DQ ⊊ DC on the membership side).
3. Auditor correctness: brute-force cross-check on small grids (≤ 6×6) that `forced`
   cells truly have unique completions within the family.
4. Throughput: generation must sustain the 256 × 15k-step budget (~3.8M pictures) or
   be pre-generated to disk; either is fine, but decide before Phase 1.

## 6. Phased execution plan

| Phase | Content | Runs (warm-up + downstream) | Gate to proceed |
|---|---|---|---|
| **0. Reproduction** (P1) | Re-run `cifar100-dyck`, `cifar100-random` on the experiment branch | 2 | Within ±0.4 of 72.64 / 70.02 |
| **1. DW screen** | H6 arms A, D (1 seed); H7 arms A–E + rule110+sincos2d retro-cell (1 seed) | ~8 | Any DW arm > 71.0 |
| **2. Verdicts** | H6 A/B/C/D at 3 seeds; H11 masking ablation (1 seed, then 3 on the winner); H10 sweep (1 seed each) | ~15–18 | H6 success or partial; H9 margin ≥ 1.0 |
| **3. Hierarchy** | H8: DN/DQ/DC + controls (1 seed screen, 3 seeds on extremes); H9b | ~10–12 | Interpretable gradient or informative flat |
| **4. Breadth + scale** | Best condition on Tiny-ImageNet, STL-10, FOOD-101, CIFAR-10 (parent Table: random 55.42 / 60.52 / 74.52 / 91.29; warm-up 58.20 / 66.48 / 79.47 / 92.81); single ViT-B ImageNet-1K run vs. the +1.72 anchor | ~6 + 1 large | — |

Each phase's negative result is itself publishable within the project's framing: Phase 2
failure with A ≈ D is the "generic properties, not operator" story with a second source
class; Phase 3's DC-below-random (if observed with low determinacy) causally validates
the §5 theory.

**Compute note.** ViT-T warm-up (15k × 256) and CIFAR-100 downstream (300 epochs) match
existing per-run costs in the repo — Phases 0–3 total ≈ 40–45 such runs, comparable to
the CA study's footprint. The single ViT-B/ImageNet run in Phase 4 dominates cost and is
gated behind three prior verdicts by design.

## 7. Risks and mitigations

| Risk | Signal | Mitigation |
|---|---|---|
| Native 2D presentation is intrinsically penalized for transformer warm-up (spatial-dyck was not an artifact) | H7: C ≥ A even with sincos2d | Rasterized-1D DW becomes the primary arm; 2D Dyck still contributes vocabulary + constraint distribution in 1D form |
| DC/DQ sampler bias confounds H8 | Structure-statistic drift between sampling strategies | Dual-sampler check; report statistics; restrict claims to DW/DN if unresolved |
| Corner-close-only masking is locally shortcut-able (a d-corner's neighbors leak its type) | High masked-corner accuracy at distance 1, collapse at distance > 3 in the H7 diagnostic | Add minimum-match-distance filter to the maskable set; re-run |
| Fixed layout → absolute-position shortcut | H7 arm E ≪ A | Make translation jitter default; note the spatial-dyck tension (§5.1 of report) is resolved by jitter-without-permutation |
| K = 258 exceeds frozen-orthogonal capacity at ViT-T width 192 | Embedding construction fails/overlaps | Cap sweep at K ≤ 190 or use scaled near-orthogonal init; document either way |
| Seed noise swamps effects | All Phase-2 CIs overlap | The 0.7-pt/2σ rule (P7) is binding; widen to 5 seeds only for the final headline contrast |
| Generation throughput too low for on-the-fly sampling | Steps/sec drops vs. Dyck baseline | Pre-generate to disk (3.8M pictures ≈ small: 196 bytes/picture ≈ 750 MB) |

## 8. What would change the plan

- **H6 success + H9 margin ≥ 1.0:** 2D Dyck becomes the flagship; the
  curriculum direction (Type-2 → Type-1 → FractalDB → images; note FractalDB warm-up
  *alone* scored 64.61 on C100 in the parent paper, below random 68.52) is revisited
  only after the hierarchy sweep, with 2D Dyck inserted as a stage.
- **H6 partial + H7 shows rasterized ≥ native:** pivot to "2D languages, 1D
  presentation" and reframe the paper around the presentation/determinacy theory.
- **Treatment ≈ control everywhere:** the triad theory survives but "genuinely 2D
  structure" is dropped as a transfer axis; write the two-source negative result
  (CA + 2D Dyck) as a bounded claim about what procedural warm-up actually uses.
